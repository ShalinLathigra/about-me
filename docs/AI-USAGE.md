# How will I be using AI during this project?

## Allowed

- If I would be asking on a stack overflow forum, I can ask AI
	- How do I do X in nginx
	- Why is my docker compose network not working
- Finding references
	- HTML Tag references
	- Same for CSS and HTMX
- Config file setup is allowed, but I cannot blindly copy
	- Must note down steps and be able to explain any issue solved with AI
- Asking about common structures and workflows
	- This mostly falls under "would I be asking on stack overflow"


## Not Allowed

- No core functionality will be written by AI
	- Goal is for this to be 95% human written slop
- No design decisions will be made by AI
	- Gathering references is fine, but I need to read and decide myself

## Allowable Grey Area

- Nothing yet, but it'll come up I'm sure
